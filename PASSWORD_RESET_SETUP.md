# Восстановление пароля — что настроить в Supabase

Код готов: «Забыли пароль?» на `/login` → письмо со ссылкой → `/change_password` → новый пароль.
Пока не выполнены шаги ниже, письма доходят только участникам команды Supabase-проекта.

## 1. Свой SMTP

**Authentication → SMTP Settings**

- [ ] Подключить почтовый сервис (например, Resend или Brevo — есть бесплатные тарифы).
- [ ] Подтвердить домен zubrika.ru у выбранного сервиса (DNS-записи SPF/DKIM).
- [ ] **Authentication → Rate Limits** — поднять лимит писем в час.

## 2. Шаблон письма

**Authentication → Email Templates → Reset Password** — заменить ссылку в шаблоне на:

```html
<a href="{{ .RedirectTo }}?token_hash={{ .TokenHash }}&type=recovery">Сбросить пароль</a>
```

Текст письма — на русском, например:

```html
<h2>Восстановление пароля</h2>
<p>Чтобы задать новый пароль для Zubrika, перейдите по ссылке:</p>
<p><a href="{{ .RedirectTo }}?token_hash={{ .TokenHash }}&type=recovery">Сбросить пароль</a></p>
<p>Если вы не запрашивали сброс, просто проигнорируйте это письмо.</p>
```

## 3. Разрешённые адреса

**Authentication → URL Configuration → Redirect URLs** — добавить:

- [ ] `https://www.zubrika.ru/change_password`
- [ ] `http://localhost:3000/change_password`

## 4. Проверка

- [ ] На `/login` нажать «Забыли пароль?», ввести свою почту → письмо пришло.
- [ ] Ссылка открывает форму нового пароля, после сохранения — главная под своим аккаунтом.
- [ ] Повторный клик по той же ссылке → «Ссылка недействительна».
- [ ] Вход с новым паролем работает.
