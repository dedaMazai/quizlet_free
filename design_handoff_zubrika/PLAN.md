## Итерация 0 — план
Claude Code читает README/PLAN/BACKLOG, `CLAUDE.md`, макеты; составляет список файлов на каждую итерацию; отмечает расхождения макета с данными. **Код не пишется.**

## Итерация 1 — токены и тема
- Шрифты Fira Sans / Condensed / JetBrains Mono локально + `@font-face`.
- Все ramp-переменные, сигнальные цвета (`--color-success*`, `--color-error*`, `--color-warning*`), цвета уровней серии (`--streak-0…4`, `--streak-0…4-tint`), motion-токены (`--motion-*`, `--ease-*`) → `global.scss` + `globalCssVariables[Theme.LIGHT]`.
- `LightTheme`: radius 0, primary #5980a6, фон #f2f2f3, шрифт Fira Sans, controlHeight 38; оверрайды Tabs, Segmented, Table, Button, Input, Modal, Dropdown, Tag.
- `lucide-react`.
- **Готово, когда:** typecheck/lint зелёные; существующие страницы не сломаны; кнопки и поля квадратные, новый шрифт.

## Итерация 2 — примитивы
`Blueprint`, `Kicker`, `SectionHeader`, `MasteryBar` (3 сегмента, порог 80% → сигнал «результат»), `TickProgress` (N сегментов, состояния done/correct/wrong/current/todo, wrong со штриховкой), `AccentPanel`, `SectionTabs`, `StatCell`, `DueBadge` (обычный / срочный ≥15 / «Всё повторено»), `StreakFlame` (уровень по числу дней). Сторибук не нужен — проверочная страница `/dev/ui` за флагом.
