# Бэклог — спецификации без макетов

Всё ниже строится **из той же системы** (токены README §1). Не вводить новых цветов, шрифтов, радиусов.

## 1. Пустые состояния
Компонент `EmptyState`: kicker (Mono 11, neutral-700) · заголовок Condensed 600 28px · одна строка пояснения 14px · **одно** primary-действие (+ опционально ghost). Без иллюстраций и маскотов; слева/сверху — иконка lucide 32px stroke 1.25 в квадрате 64×64 с рамкой divider. Выравнивание по левому краю в контенте, по центру — в фокус-режиме.

| Где | Kicker | Заголовок | Действие |
|---|---|---|---|
| Главная, нет колод | НАЧАЛО | Создайте первую колоду | «Создать колоду» · ghost «Импорт из Excel» |
| Главная/повторение, долг 0 | ВСЁ ПОВТОРЕНО | На сегодня всё. Следующие 18 — завтра | «Учить новые» (из следующего шага) |
| Библиотека, поиск пуст | НИЧЕГО НЕ НАЙДЕНО | По «{q}» нет слов | «Сбросить фильтры» |
| Избранное пусто | ИЗБРАННОЕ | Отмечайте трудные слова звёздочкой | «К колодам» |
| Циклы пусто | ЦИКЛЫ | Записывайте слова по порядку, как в тетради | «Создать цикл» |
| Прогресс, нет данных | ПРОГРЕСС | Статистика появится после первого занятия | «Начать заучивание» |
| Колода без слов | КОЛОДА ПУСТА | Добавьте 10–20 слов, чтобы начать | «Добавить слова» · ghost «Импорт» |

В hero главной при долге 0: тёмное поле остаётся, число заменяется на ✓ 96px (сигнал «результат»), текст «Долг закрыт», кнопка «Учить новые».

## 2. Скелетоны
Повторяют геометрию итоговых блоков (размеры фиксированы → нет layout shift). Блоки-полосы без скруглений; shimmer `linear-gradient(90deg, n-200, n-100, n-200)`, `background-size: 800px`, 1.4 с linear infinite; на тёмном поле — accent-800/700. Появление данных: opacity 0→1 за base (220 мс). Показывать скелетон только если загрузка > 200 мс. Пример — блок 6.0.

## 3. Тосты и ошибки
- Позиция: снизу слева (над таб-баром на мобильном), ширина 360, квадратные, рамка divider, фон bg, shadow-md.
- Слева полоса 3px цвета смысла: результат / ошибка / срочно / нейтральный (accent). Иконка lucide 18. Текст 14, опц. действие ghost («Отменить» для удаления — 6 с).
- Время: 4 с (с действием — 6 с), пауза при наведении, максимум 3 в стеке.
- Ошибка сети: плашка во всю ширину над контентом, «Нет соединения — изменения сохранятся, когда сеть вернётся».
- Лимит ИИ: при остатке ≤3 — плашка «срочно» рядом с ИИ-кнопками; при 0 — кнопки disabled с тултипом «Лимит обновится 1-го числа».
- Заменить `message.*`/`notification.*` AntD на свой `useToast` (обёртка над `App.useApp` с кастомным рендером).

## 4. Палитра ⌘K
- Открытие: ⌘K / Ctrl+K, клик по полю поиска в топбаре, `/` на любой странице вне инпутов.
- Модалка 640px сверху (top 12vh), поле 52px без рамки + разделитель; список группами: **Действия** (Повторить N · Новая колода · Добавить слова в последнюю колоду · Учить новые), **Колоды**, **Слова** (слово — перевод — колода), **Перейти** (все разделы и вкладки).
- Клавиатура: ↑↓, Enter, Esc; Mono-подсказки справа (↵, ⌘N…). Пустой запрос — недавние колоды + действия.
- Перенести сюда `GlobalSearchResults` с главной; серверный поиск по словам — существующий `useGetCardsPageQuery` с debounce 200 мс.

## 5. Онбординг (первый вход)
Fullscreen в стиле фокус-режима, 3 шага, прогресс из 3 делений, «Пропустить» всегда доступно:
1. **Цель дня**: 10 / 20 / 30 / 50 карточек (сегменты 56px), подпись «≈ 3 / 6 / 9 / 15 минут».
2. **Первая колода**: три карточки-выбора — «Импорт из Excel», «Ввести слова» (CardEditor), «Готовый набор: неправильные глаголы, группа 1» (из IrregularVerbsPage).
3. **Первая сессия**: «Колода готова — 20 слов. 2 минуты на первое знакомство» → сессия «Карточки» → итог сессии с началом серии (уровень «Искра»).
Флаг `onboarding_done` в user settings; цель дня — туда же (используется на главной).

## 6. Тёмная тема
Вывести `Theme.DARK` из тех же ramp’ов:
| Токен | Тёмное значение |
|---|---|
| bg | `#141b23` (между accent-900 и neutral-900) |
| surface | `#1b2530` |
| text | `#e9edf2` |
| divider | `rgba(233,237,242,.14)` |
| accent | `#749dc4` (accent-500 — для контраста на тёмном) |
| тёмное поле (hero) | `#0e141a` + рамка divider |
| hover | `rgba(116,157,196,.12)` |
| сигналы | те же оттенки, L +0.08; тинты — L 0.25, C/2 |
| уровни серии | те же, без изменений |
Тени заменить на рамку + `0 12px 32px rgba(0,0,0,.5)` только у оверлеев. Переключатель — Настройки (Светлая / Тёмная / Как в системе). Проверить контраст всех пар ≥4.5:1.

## 7. «Следующий шаг» на главной — правила
Показывать до 3 карточек, по приоритету:
1. Незавершённый раунд цикла заучивания (если есть «новые сегодня» < daily) → «Продолжить».
2. Колода с фразами и примерами, давно без «Пропусков» (≥3 дня) → «Пропуски».
3. Текущий шаг дорожной карты (первый непройденный) или текущая группа грамматики → «Тренировать».
4. Колода с наибольшим числом новых слов → «Заучивание».
Каждая карточка: kicker режима, заголовок, одна строка «что будет», 7-сегментный прогресс, мета + CTA.

## 8. Анимации (итерация 17)
Токены: `--motion-instant 80ms`, `--motion-fast 140ms`, `--motion-base 220ms`, `--motion-slow 360ms`, `--motion-deliberate 600ms`; `--ease-standard cubic-bezier(.2,0,0,1)`, `--ease-enter cubic-bezier(0,0,0,1)`, `--ease-exit cubic-bezier(.3,0,1,1)` (exit = 0.7× длительности).

| Элемент | Триггер | Движение | Токен |
|---|---|---|---|
| Смена страницы | навигация | контент opacity 0→1, translateY 8→0; оболочка неподвижна | base · enter |
| Вкладки раздела | клик | индикатор скользит (x + width) | fast · standard |
| Сайдбар 236↔76 | стрелка | width; подписи fade за первые 40% | slow · standard |
| Hero «42» | первый показ за день | count-up 0→N, столбики прогноза растут снизу, stagger 30 мс | deliberate · enter |
| Полосы освоения | вход во viewport | scaleX 0→1 от левого края, сегменты по очереди | deliberate · enter |
| Неделя серии | загрузка главной | заливка слева направо, stagger 40 мс; «сегодня» один «вдох» | base · enter |
| Новый уровень серии | переход порога | плашка перекрашивается, огонь scale 1→1.15→1, цвет перетекает | deliberate |
| Карточки «Следующий шаг» | появление | opacity + translateY 12→0, stagger 40 мс, ≤6 | base · enter |
| Вариант ответа | выбор | верно: заливка из точки клика + галочка stroke-draw; неверно: сдвиг ±6px ×2 | fast / base |
| Прогресс сессии | ответ | деление заполняется, следующее подсвечивается | base |
| Автопереход | верный ответ | линия под «Дальше» 1.2 с linear; Enter — сразу | linear 1200 |
| Переворот карточки | клик/пробел | rotateY 180°, perspective 1200, backface hidden | slow |
| Собери фразу | клик по слову | FLIP-перелёт в строку ответа, место — пунктир | base |
| Итог сессии | конец | серия 12→13 перелистыванием цифры, огонь scale, статистика stagger | deliberate |
| Модалка / шторка | открытие | фон opacity; окно scale .98→1 / шторка translateY 100%→0 | base / exit |
| Тост | появление | translateY 8→0 + opacity; уход — opacity | fast |

Правила: только transform/opacity; `prefers-reduced-motion: reduce` → всё = opacity 80 мс, счётчики сразу итог; «праздничные» анимации (count-up, уровни) — раз в день/по событию; никаких бесконечных декоративных петель (кроме shimmer скелетона). Реализация: CSS-transitions + небольшой хук `useCountUp`; для FLIP и последовательностей — `motion` (framer-motion) только в местах из таблицы.
