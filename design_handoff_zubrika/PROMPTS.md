# Промпты для Claude Code

Положите `design_handoff_zubrika/` в корень `quizlet_free/`. **Одна итерация = один промпт = один PR.** Между итерациями — `/clear`, чтобы контекст был чистым. В начале каждого промпта Claude Code сам перечитает нужные разделы.

Общая приписка (добавляйте в конец любого промпта):
```
Правила: точно по макету, ничего не добавлять и не «улучшать». Стек и правила — из CLAUDE.md
(AntD, CSS Modules, FSD, t() для строк, без inline-стилей). Значения — только из токенов README §1.
Логику и API не менять, если итерация этого не требует. В конце: npm run typecheck, npm run lint,
и список расхождений с макетом по номерам экранов.
```

новые компоненты, затрагиваемые хуки, риски. Отметь, где макет расходится с текущими данными,
